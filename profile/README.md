# Greenhead Labs LLC

**Wyoming-based crypto infrastructure and AI agent company.**

We build at the intersection of decentralized identity, autonomous AI systems, and blockchain payments — with a focus on the XRP Ledger and Flare Network.

---

## What We Build

- **Decentralized Identity (DID)** — Verifiable credentials anchored on XRPL, linked across Ethereum and Flare Network
- **AI Agents** — Autonomous on-chain agents that sign transactions, execute tasks, and interact with web3 protocols
- **Web3 Payments** — Machine-to-machine micropayment infrastructure using the x402 HTTP payment protocol
- **x402.greenhead.io** — Pay-per-call XRPL API using HTTP 402 micropayments — no accounts, no API keys
- **TradeDesk** — XRPL meme coin sniper bot with autonomous on-chain execution
- **Quack Protocol** — Internal automation layer connecting our agents, dashboards, and on-chain operations
