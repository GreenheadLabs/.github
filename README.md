## What is this repository?

This is the special [`.github` repository](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for the [@GreenheadLabs](https://github.com/GreenheadLabs) organization. GitHub treats it specially: the files here provide **organization-wide defaults** that automatically apply to every repository in the org that does not define its own equivalent.

In other words, you don't need to copy a `CONTRIBUTING.md`, `SECURITY.md`, or issue template into every repo — they live here once and are inherited everywhere.

## How the defaults work

- **Community health files** (`CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`, issue/PR templates) placed in this repo apply to any org repo that lacks its own copy. A repository's own file always wins over the org default.
- **The org profile** is rendered from [`profile/README.md`](profile/README.md) — note that only that exact path is used for the profile page; this root `README.md` is not.
- Changes take effect automatically once merged to the default branch. There is nothing to build, deploy, or install.
