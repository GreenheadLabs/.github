# Support

Thanks for using Greenhead Labs projects! Here's how to get help.

## Before you ask

- Check the specific repository's `README.md` and documentation.
- Search [existing issues](../../issues?q=is%3Aissue) — your question may already be
  answered.

## Getting help

| I want to... | Do this |
|--------------|---------|
| Report a bug | Open a [bug report](../../issues/new?template=bug_report.yml) |
| Request a feature | Open a [feature request](../../issues/new?template=feature_request.yml) |
| Ask a general question | Start a discussion (if enabled) or open an issue |
| Report a security issue | Follow our [Security Policy](SECURITY.md) — **do not** open a public issue |
| Learn about Greenhead Labs | Visit our [organization profile](https://github.com/GreenheadLabs) |

## Response expectations

We're a small team building in public. We do our best to respond to issues and
questions promptly, but response times may vary. Security reports are always
prioritized — see [SECURITY.md](SECURITY.md).
